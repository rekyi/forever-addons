# WoW Forever addons

Collection of addons I created for WoW Forever - mostly overhauled/improved versions of my private WoW Classic addons. Each addon has its own folder at the top level.
Currently not on CurseForge (no plans yet).

| Addon                          | Version | Description                                                                              |
| ------------------------------ | ------- | ---------------------------------------------------------------------------------------- |
| [Momentum](Momentum/README.md) | 1.0     | Resource bar with thresholds, swing timer and an icon row for buffs, procs and cooldowns |

## Installation

Copy the addon folder (for example `Momentum`) to `World of Warcraft/_forever_/Interface/AddOns/`.
